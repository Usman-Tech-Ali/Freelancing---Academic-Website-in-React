
# Globalassigntech Academic Writing Platform

This is a modern academic writing services website built with **React**, **Vite**, and **Tailwind CSS**. It provides a professional platform for students to explore and request academic writing services, including dissertation, essay, research paper, and more. The site features a clean UI, responsive design, and interactive components.

## 🚀 Features

- Modern React (with hooks and functional components)
- Vite for fast development and builds
- Tailwind CSS for utility-first styling
- Framer Motion for animations
- EmailJS integration for contact forms
- Responsive and mobile-friendly design
- Modular component structure

## 🖥️ Main Pages

- **Home**: Landing page with hero, services, features, testimonials, and call to action.
- **About Us**: Company story, timeline, stats, values, and leadership team.
- **Academics**: Academic writing categories and services with filter and modal details.
- **Services**: Detailed service offerings and testimonials.
- **Contact**: Contact form (EmailJS), contact info, and map.

## 🛠️ Getting Started

1. **Install dependencies:**
	```sh
	npm install
	```
2. **Run the development server:**
	```sh
	npm run dev
	```
3. **Build for production:**
	```sh
	npm run build
	```
